# Geräte freigeben und widerrufen

Jedes Gerät, das verkaufen oder einchecken soll, muss von der Inhaberin
freigegeben werden. Das gilt für das iPad am zweiten Standort genauso wie für das
Telefon einer Aushilfe.

## Freigeben

1. Beide Geräte öffnen **Verbinden**.
2. Ein Gerät erzeugt einen Code, das andere scannt oder fügt ihn ein — siehe
   [Verbinden](/connecting).
3. Auf dem Gerät der Inhaberin erscheint das neue Gerät unter **Registry** als
   wartend.
4. Rolle und Standort wählen, freigeben.

Ab diesem Moment darf das Gerät Karten verkaufen und entwerten. Es steht in der
Geräteliste, die jedes andere Gerät ebenfalls erhält — daran erkennen alle, wessen
Unterschrift gültig ist.

## Widerrufen

Ein Gerät wird nie gelöscht, sondern **widerrufen**, mit Zeitpunkt.

Das ist wichtiger, als es klingt: Alles, was das Gerät **vor** dem Widerruf
signiert hat, bleibt gültig. Ein Tag rechtmäßig verkaufter Karten wird nicht
ungültig, nur weil das Gerät später abhandenkommt. Alles danach wird abgelehnt.

<div class="no-server">

**Der Widerruf braucht eine Begegnung**
Ein widerrufenes Gerät erfährt davon erst, wenn es das nächste Mal einem anderen
Gerät begegnet. Bis dahin kann es weiter signieren — und diese Einträge werden
später abgelehnt, sobald der Widerruf ankommt. Bei einem verlorenen Gerät gilt
also: widerrufen **und** damit rechnen, dass ein paar Einträge nachlaufen.

</div>

## Rollen

| Rolle          | Darf                                                  |
| -------------- | ----------------------------------------------------- |
| **Inhaberin**  | alles, einschließlich Geräte freigeben und widerrufen |
| **Front-Desk** | verkaufen, einchecken, Buchungen bestätigen           |
| **Teacher**    | dasselbe wie Front-Desk, gedacht für Kursleitungen    |

Die Registry selbst kann nur die Inhaberin ändern. Ein Front-Desk-Gerät, das sie
ändern könnte, könnte sich selbst eintragen.
