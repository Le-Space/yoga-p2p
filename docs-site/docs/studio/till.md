# Karte verkaufen

Unter **Kasse**. Der Schüler muss vorher mit diesem Gerät verbunden gewesen sein —
sonst steht er nicht in der Liste.

1. Schüler wählen
2. Karte wählen
3. **Bar erhalten**

Das war es. Es gibt keinen zweiten Schritt und keine Bestätigung von irgendwo.

## Was dabei passiert

Der Verkauf wird als Eintrag in das Kartenkonto des Schülers geschrieben,
**unterschrieben von diesem Gerät**. Diese Unterschrift ist der Beleg: Sie sagt,
welches Gerät an welchem Standort das Geld genommen hat, und sie lässt sich noch
in Jahren prüfen.

Ein Guthaben wird nirgends gespeichert. Es wird jedes Mal aus den Einträgen
gerechnet — deshalb können zwei Standorte unabhängig voneinander zum selben
Ergebnis kommen, ohne sich abzustimmen.

## Wenn ein Verkauf kurz hängt

Direkt nach dem ersten Koppeln kann ein Verkauf ein paar Sekunden brauchen. Das
ist kein Fehler: Die Erlaubnis, in das Kartenkonto zu schreiben, muss erst bei
diesem Gerät ankommen. Die App wartet und versucht es weiter, statt einen Verkauf
abzulehnen, der gleich erlaubt ist.

## Karte auf ein neues Telefon übertragen

Wenn jemand seinen Passkey verliert, ist seine Kennung weg — das bezahlte
Guthaben nicht.

1. Der Schüler richtet sein neues Telefon ein und verbindet es mit euch.
2. Unter **Kasse → Karte auf neue DID übertragen** wählt ihr alt und neu.
3. **Guthaben übertragen**.

Das Restguthaben wandert auf die neue Karte, die alte wird entwertet. Verbrauchte
Stunden kommen nicht zurück, und die Gültigkeitsdauer bleibt, wie sie war — eine
Übertragung ersetzt eine Karte, sie verkauft keine neue.

<div class="no-server">

**Falls dabei eine Meldung kommt**
Sollte die App melden, dass die alte Karte nicht entwertet werden konnte, steht
das Guthaben gerade **doppelt**. Wiederholt den Vorgang, bis die Meldung
verschwindet. Die App sagt das ausdrücklich, statt es zu verschweigen — nur ein
Mensch kann das auflösen.

</div>
