# English translations

**[Deutsch](../../README.de.md)** · English

The project's documents are written in German. Code comments reference the German
paths — 88 of them at last count — so those files stay where they are and the
translations live here.

**The German file is always the original.** When a translation and its source
disagree, the German one is right and the translation is behind. Each file says so
at the top rather than leaving it to be discovered.

| [PRIVACY.md](PRIVACY.md)  | translated                                                                |
| [DESIGN.md](../DESIGN.md) | German only — mostly token tables and measured contrast values            |
| [LIMITS.md](../LIMITS.md) | German only — 485 lines, translated as it stabilises                      |
| [PLAN.md](../PLAN.md)     | German only — 845 lines, the binding plan; translating it risks two plans |

The last three are named here rather than quietly omitted. Two of them are long
and still moving, and a half-finished translation of a _binding_ plan is worse
than none: it invites somebody to follow the stale copy. They get translated when
they settle, and the table says so until then.

Anyone who needs the substance of `LIMITS.md` in English will find most of it in
the [README](../../README.md) and in the commit messages, which are written in
English throughout.
